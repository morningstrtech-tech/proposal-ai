n# ProposalAI — Premium Next.js Edition

A high-end AI proposal generator built with **Next.js 14 (App Router)**, **TypeScript**, and **Framer Motion**.

## 🚀 Cara Menjalankan

Karena pembatasan lingkungan saat ini, Anda perlu menjalankan instalasi dependensi secara manual:

1.  Buka terminal di folder ini.
2.  Jalankan perintah berikut untuk menginstal semua package:
    ```bash
    npm install
    ```
3.  Jalankan server pengembangan:
    ```bash
    npm run dev
    ```
4.  Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## ✨ Fitur Premium
- **App Router & Server Components**: Arsitektur modern Next.js.
- **Framer Motion**: Animasi transisi step yang sangat halus.
- **Editorial Design**: Layout premium dengan tipografi Outfit & Inter.
- **Glassmorphism**: Efek visual modern dengan backdrop blur.
- **Print Optimization**: Desain khusus untuk mencetak proposal langsung ke PDF.

## 🛠️ Pengembangan Selanjutnya
- Integrasikan dengan API Anthropic atau OpenAI di `src/app/api/generate/route.ts`.
- Tambahkan database (Supabase/Prisma) untuk menyimpan riwayat proposal.
- Tambahkan autentikasi (NextAuth.js).
